# Systems Case Studies

Selected architecture and engineering case studies from private systems built by **Göktürk Kahriman**, Full-stack & AI Systems Developer.

These documents explain the problems, system boundaries, and engineering decisions behind commercial, client, and personal systems whose source cannot be published. They are intentionally sanitized: no proprietary source, production credentials, customer records, investment data, private prompts, or commercially sensitive configuration is included.

## Publication Boundary

The case studies describe verified capabilities at an architecture level. Private repositories and production systems remain private for commercial, client, security, and data-protection reasons. Where a system has a public-facing website, the case study links to that surface without implying that the operational source is public.
